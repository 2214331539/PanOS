# UI 视觉与交互规范

版本：v0.1  
日期：2026-06-07

## 设计原则

PanOS 的视觉语言是“受 macOS 启发的个人桌面”，但不直接复制 macOS 图标和系统素材。整体应保持玻璃拟态、真实壁纸、窗口层级、轻动效和强个人气质。

关键词：清透、克制、研究感、创造感、轻微科技感、真实桌面。

| App 图标 | 16px |
| Window | 18px |

## 阴影和玻璃效果

| 层级 | 样式 |
| --- | --- |
| Menu Bar | `backdrop-blur: 18px`，轻边框，无重阴影 |
| Dock | `backdrop-blur: 22px`，中等阴影 |
| Window | `backdrop-blur: 26px`，大阴影，1px 半透明边框 |
| Card | 轻阴影或无阴影，依靠边框和背景区分 |
| Spotlight | 背景遮罩 + 模糊，浮层阴影强于普通窗口 |

禁止使用离散渐变球、装饰性光斑和大面积粒子背景。

## 核心组件规范

### Menu Bar

- 桌面端高度 36px，固定顶部。
- 背景使用玻璃效果。
- 左侧显示 PanOS，下拉菜单。
- 中间显示当前激活 App 名称。
- 右侧显示 Search、Theme、Clock。
- 所有按钮必须有可见 focus 状态。

### Dock

- 桌面端底部居中，宽度随 App 数量自适应，最大宽度不超过视口减 32px。
- 高度 76px。
- 图标 48px，hover 可放大到 58px，但 Dock 高度不跳动。
- 已打开 App 在图标下方显示 4px 小圆点。
- 点击未打开 App：打开窗口。
- 点击已最小化 App：恢复窗口。
- 点击已打开 App：置顶窗口。

### Window

- 默认尺寸：宽 880px，高 620px。
- 最小宽度：桌面端 520px。
- 最大宽度：`calc(100vw - 48px)`。
- 最大高度：`calc(100vh - 136px)`。
- 标题栏高度 44px。
- 左侧三个窗口按钮：关闭、最小化、最大化。
- V1 支持打开、关闭、最大化、置顶。
- V2 支持最小化恢复。
- V3 支持拖拽和多窗口细节增强。

### Button

| 状态 | 规范 |
| --- | --- |
| Default | 背景清晰，文字对比足够 |
| Hover | 背景亮度或透明度变化，移动 0 到 1px |
| Active | 轻微压下，scale 0.98 |
| Focus | 2px 可见 focus ring |
| Disabled | 透明度 0.45，不触发 hover |
| Loading | 显示 spinner，保留原宽度避免跳动 |

按钮文案必须短。能用图标表达的工具操作使用 lucide-react 图标，并提供 tooltip。

### Card

- 卡片圆角 8px。
- 卡片只用于重复内容项，如文章卡片、项目卡片、链接卡片、图片信息卡片。
- 不允许卡片套卡片。
- 卡片 hover 只做轻微上浮或边框变化。

### Spotlight

- 快捷键：桌面端 `Cmd/Ctrl + K`。
- 背景遮罩：`rgba(0,0,0,0.32)`。
- 浮层宽度：桌面端 640px，移动端 `calc(100vw - 24px)`。
- 输入框高度 52px。
- 搜索结果显示图标、类型、标题、摘要。
- 上下键切换结果，Enter 打开，ESC 关闭。

### Lightbox

- Gallery 图片点击打开。
- 支持左右键切换和 ESC 关闭。
- 图片不得被信息侧栏遮挡。
- 移动端信息侧栏改为底部抽屉。

## 动效规范

使用 Motion 作为唯一动效库。

| 动效 | 时长 | 曲线 |
| --- | --- | --- |
| 窗口打开 | 180ms | ease-out |
| 窗口关闭 | 140ms | ease-in |
| Spotlight 打开 | 160ms | ease-out |
| 卡片 hover | 120ms | ease-out |
| Dock hover | 120ms | spring，低弹性 |
| 页面淡入 | 160ms | ease-out |

不使用复杂全屏 3D、鼠标拖尾、大面积滚动视差、强弹跳动画。用户启用 `prefers-reduced-motion` 时，所有 scale 和位移动效必须关闭，仅保留透明度变化。

## 响应式规则

### 桌面端，大于等于 1024px

- 使用桌面窗口系统。
- Dock 固定底部。
- 窗口可以并存。
- Widget 分布在桌面左右区域。

### 平板，768px 到 1023px

- 保留 Dock。
- App 打开后接近全屏。
- Widget 减少到 Now、Latest、Status。

### 移动端，小于 768px

- 首页改为 iOS 主屏逻辑。
- App 图标网格显示在欢迎区下方。
- App 打开后全屏。
- 顶部显示返回桌面按钮。
- Dock 保留 4 到 5 个核心入口：About、Articles、Projects、Gallery、Contact。
- 不显示多窗口并存。

## 文案状态

### 加载

`Booting PanOS...`

### 空状态

`这里还没有内容。但一个新的想法可能很快会被放进来。`

### 404

`This file does not exist in PanOS. 也许它还只是一个没被写下来的想法。`

### 搜索无结果

`没有找到匹配内容。换个关键词试试。`

## 可访问性

- 所有可点击元素必须可键盘访问。
- 所有图标按钮必须有 `aria-label` 或 tooltip。
- 图片必须有 alt。
- 表单错误必须显示在对应字段附近。
- 文字和背景对比度至少满足 WCAG AA。
- 不依赖颜色作为唯一状态表达。

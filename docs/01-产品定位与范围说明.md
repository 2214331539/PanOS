# 产品定位与范围说明

版本：v0.1  
日期：2026-06-07

## 一句话定位

PanOS 是潘廷峰的个人操作系统：一个运行在浏览器里的个人桌面，用 Dock、窗口、Widget、Spotlight 和内容应用，把文章、项目、研究、图片、想法、时间线和社交入口组织成一个可探索的数字空间。

## 形象化框架

访问者进入 PanOS，就像打开一台属于小潘同学的个人电脑。

屏幕上有真实桌面壁纸、半透明菜单栏、底部 Dock、几个状态小组件，以及一个默认弹出的欢迎窗口。用户不是在滚动一个传统博客首页，而是在探索一个人的创作桌面：点开 Articles 像打开文档文件夹，点开 Projects 像进入 App Store，点开 Research 像进入研究者工作台，点开 Gallery 像进入 Photos，点开 Links 像打开社交账号控制面板。

## 产品不是

PanOS 不是普通个人博客，不是作品集模板，不是单页简历，也不是完全复刻 macOS 的玩具系统。

它借用操作系统的空间隐喻，但目标不是“仿真”，而是让个人内容更有秩序、更有探索感、更能表达“AI 研究者 + Web 开发者 + 产品探索者 + 内容创作者”的复合身份。

## 目标用户

| 用户             | 进入动机                    | 期望体验                                           |
| -------------- | ----------------------- | ---------------------------------------------- |
| 研究者 / 同学 / 合作者 | 了解研究方向、论文计划、实验记录        | 快速看到 Agent Memory、Tool Retrieval、ToolHCL 等研究脉络 |
| 招聘方 / 项目合作方    | 判断能力、项目质量、表达方式          | 通过 Projects、Articles、About 快速建立信任              |
| 开发者 / 创作者      | 阅读技术文章、看项目实现、找灵感        | 能通过 Spotlight 或分类进入具体内容                        |
| 内容平台粉丝         | 找到小红书、抖音、B 站、GitHub 等入口 | Links 像控制面板一样清晰                                |
| 站点管理员本人        | 管理文章、项目、图片、研究笔记、时间线     | 后台可维护内容，避免频繁改代码                                |

## 核心体验

1. 进入时有“启动 PanOS”的仪式感。
2. 第一屏展示个人桌面，而不是传统文章列表。
3. 所有公开内容都以 App 形式组织。
4. 桌面端是 macOS 风格桌面，移动端是 iOS 风格主屏。
5. 内容越来越多后，Spotlight 成为最高效入口。
6. 后台管理保证内容长期更新，而不是一次性静态页面。

## 核心模块

| --------------- | ------------------------------ | ----- |
| Desktop Shell   | 顶部菜单栏、Dock、壁纸、欢迎窗口、Widget、窗口容器 | 必做    |
| About           | 个人介绍、身份标签、当前关注、系统信息式面板         | 必做    |
| Articles        | 正式文章、技术笔记、长文、MDX 内容详情          | 必做    |
| Projects        | Web、AI、产品实验、研究工具展示             | 必做    |
| Gallery         | 图片作品、设计图、项目截图、AI 图片            | 必做    |
| Links           | GitHub、小红书、抖音、B 站、邮箱等入口        | 必做    |
| Contact         | 合作、研究交流、邮箱、简历下载、留言表单           | 必做    |
| Ideas           | 碎片灵感、产品想法、数字花园状态               | V2    |
| Research        | 研究方向、论文笔记、实验日志、roadmap         | V2    |
| Timeline        | 最近动态、研究、项目、写作、生活时间线            | V2    |
| Spotlight       | 全站搜索入口，快捷键 Cmd/Ctrl + F        | V2    |
| Window Advanced | 拖拽、最小化、多窗口层级、快捷键增强             | V3    |
| Ask PanOS       | 基于个人内容的 AI 助手                  | V4    |

## 范围边界

### V1 必须完成

- 公开桌面首页。
- 顶部菜单栏。
- 底部 Dock。
- 欢迎窗口。
- 基础窗口打开、关闭、最大化、置顶。
- About、Articles、Projects、Gallery、Links、Contact 六个 App。
- 文章和项目详情页。
- 基础后台管理。
- 数据库存储核心内容。
- 对象存储图片、视频、简历等文件。
- 移动端主屏式体验。

### V1 不做

- 访客账号系统。
- 评论区。
- 点赞收藏。
- 复杂社交关系。
- AI 助手。
- 多语言全站切换。
- 复杂窗口拖拽物理效果。
- 右键菜单。
- 支付、电商、会员系统。

### V2 做

- Ideas、Research、Timeline。
- Spotlight 全站搜索。
- 图片 Lightbox。
- 更完整的标签、分类、筛选。
- 内容后台增强。

### V3 做

- 窗口拖拽。
- 最小化到 Dock。
- 多窗口层级增强。
- 快捷键系统。
- 控制中心和动态壁纸。

### V4 做

- Ask PanOS 个人知识库 AI 助手。
- 基于文章、项目、研究笔记的检索增强问答。
- 可追问的个人研究与项目导航。

## 内容来源原则

| 内容 | 初始来源 | 后续管理方式 |
| --- | --- | --- |
| 网站名称 PanOS | 代码常量 | 不进后台，除非品牌重命名 |
| Dock App 列表 | 代码配置 | 不允许后台随意新增核心 App |
| 个人身份基础文案 | 代码配置 + site_settings | V1 可静态，V2 可后台调整 |
| 桌面壁纸 | 对象存储 | 后台设置当前壁纸 |
| Widget 内容 | 数据库 | 后台管理 |
| Articles | 数据库 | 后台管理 |
| Ideas | 数据库 | 后台管理 |
| Projects | 数据库 | 后台管理 |
| Gallery | 数据库 + 对象存储 | 后台管理 |
| Research | 数据库 | 后台管理 |
| Timeline | 数据库 | 后台管理 |
| Links | 数据库 | 后台管理 |
| Contact 留言 | 数据库 | 后台查看和归档 |

## Phase 1：工程脚手架

任务：

1. 初始化 monorepo：`panos/frontend` 和 `panos/backend`。
2. 初始化 React + Vite + TypeScript 前端。
3. 配置 Tailwind CSS 和全局 CSS variables。
4. 配置 pnpm、ESLint、Prettier、TypeScript strict。
5. 初始化 FastAPI + Python 3.12 后端。
6. 配置 uv、Ruff、mypy、pytest。
7. 配置 SQLAlchemy、Alembic、asyncpg。
8. 配置 Supabase 前端客户端、后端 JWT 校验和 Storage 访问。
9. 建立目录结构。
10. 添加基础测试框架 Vitest、Playwright、pytest。

交付物：

- 可运行的开发服务器。
- 首页空壳。
- `/admin/login` 空壳。
- SQLAlchemy model 初始文件。
- Alembic migration 初始配置。
- `.env.example`。

验收标准：

- `pnpm --dir panos/frontend lint` 通过。
- `pnpm --dir panos/frontend typecheck` 通过。
- `pnpm --dir panos/frontend test` 至少有一个基础测试通过。
- `uv run --project panos/backend ruff check .` 通过。
- `uv run --project panos/backend mypy app` 通过。
- `uv run --project panos/backend pytest` 至少有一个基础测试通过。

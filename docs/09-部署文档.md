# 部署文档

版本：v0.1
日期：2026-06-10

架构：**Vercel（前端静态站）+ Railway（FastAPI + PostgreSQL）**。

```text
浏览器 ──> Vercel (panos/frontend, Vite 静态产物 + SPA rewrite)
              │  VITE_API_BASE_URL
              ▼
          Railway (panos/backend, Dockerfile)
              │  DATABASE_URL
              ▼
          Railway PostgreSQL
```

## 一、后端（Railway）

仓库内配置：`panos/backend/Dockerfile`（含启动时自动 `alembic upgrade head`）、`panos/backend/railway.json`（健康检查 `/`、失败重启）。

步骤：

1. Railway 新建项目 → `Add Service → GitHub Repo`，**Root Directory 设为 `panos/backend`**。
2. 同项目 `Add Service → Database → PostgreSQL`。
3. 后端服务 Variables 配置（见下表）。
4. Settings → Networking → Generate Domain，得到 `https://<api-domain>`。
5. （可选）首次部署后在服务 Shell 里执行 `uv run --no-dev python -m app.db.seed` 注入种子数据。

### 后端环境变量

| 变量 | 必填 | 示例 / 说明 |
| --- | --- | --- |
| `DATABASE_URL` | ✅ | `postgresql+asyncpg://user:pass@host:5432/railway`。注意：Railway PG 给的是 `postgresql://` 前缀，**必须改成 `postgresql+asyncpg://`**。可写 `postgresql+asyncpg://${{Postgres.PGUSER}}:${{Postgres.PGPASSWORD}}@${{Postgres.RAILWAY_PRIVATE_DOMAIN}}:5432/${{Postgres.PGDATABASE}}` |
| `ADMIN_USERNAME` | ✅ | 后台登录账号 |
| `ADMIN_PASSWORD` | ✅ | 强密码（`openssl rand -hex 16`） |
| `AUTH_SECRET` | ✅ | JWT 签名密钥（`openssl rand -hex 32`） |
| `CONTACT_RATE_LIMIT_SECRET` | ✅ | `openssl rand -hex 32` |
| `BACKEND_CORS_ORIGINS` | ✅ | `https://<vercel-domain>`（多个用逗号分隔；生产**不要**设置 `BACKEND_CORS_ORIGIN_REGEX`） |
| `MEDIA_BASE_URL` | ✅ | `https://<api-domain>/media` |
| `UPLOAD_DIR` | 建议 | `/data/uploads`，并给服务挂 Railway Volume 到 `/data`（否则上传图片在重新部署后丢失） |
| `AUTH_TOKEN_TTL_SECONDS` | 可选 | 默认 86400（24h） |

> 媒体存储现状：V1 用本地磁盘 + `/media` 静态服务，Railway 必须挂 Volume 才能持久化；中期目标是切到 Supabase Storage（配置项已预留）。

## 二、前端（Vercel）

仓库内配置：`panos/frontend/vercel.json`（SPA rewrite 到 `index.html`、静态资源长缓存）。

步骤：

1. Vercel `Add New → Project` 导入仓库，**Root Directory 设为 `panos/frontend`**。
2. Framework Preset 选 Vite（vercel.json 已声明），Install/Build 命令保持默认（`pnpm install` / `pnpm build`，Vercel 自动识别 pnpm workspace）。
3. 配置环境变量（见下表）→ Deploy。

### 前端环境变量

| 变量 | 必填 | 示例 |
| --- | --- | --- |
| `VITE_API_BASE_URL` | ✅ | `https://<api-domain>/api` |
| `VITE_SITE_URL` | 建议 | `https://<vercel-domain>` |

## 三、上线检查清单

- [ ] `https://<api-domain>/` 返回 `{"name":"PanOS API","status":"running"}`
- [ ] `https://<api-domain>/api/articles` 返回数据且响应头带 `ETag`
- [ ] 前端首页桌面正常加载，Articles / Projects / Gallery / Links 四个 App 有内容
- [ ] `/admin` 未登录跳转 `/admin/login`，登录后可发文章
- [ ] 后台上传图片后刷新页面图片仍可访问（验证 Volume 挂载）
- [ ] Contact 表单提交成功（验证 CORS 配置正确）
- [ ] 手机访问 `/?app=articles` 全屏体验正常

## 四、本地模拟生产构建

```bash
# 前端产物
pnpm web:build && npx serve panos/frontend/dist

# 后端镜像
docker build -t panos-api panos/backend
docker run --rm -p 8000:8000 --env-file panos/backend/.env \
  -e DATABASE_URL=postgresql+asyncpg://postgres:postgres@host.docker.internal:5440/panos \
  panos-api
```

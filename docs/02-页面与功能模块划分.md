# 页面与功能模块划分

版本：v0.1  
日期：2026-06-07

## 路由总览

| 路由                 | 页面         | 权限  | 说明                               |
| ------------------ | ---------- | --- | -------------------------------- |
| `/`                | Desktop 首页 | 公开  | PanOS 主入口，桌面、Dock、窗口、Widget 都在这里 |
| `/articles/[slug]` | 文章详情直达页    | 公开  | 允许搜索引擎和外链直接访问文章                  |
| `/projects/[slug]` | 项目详情直达页    | 公开  | 允许外链直接访问项目                       |
| `/gallery/[slug]`  | 图片详情直达页    | 公开  | V2 可启用，用于图片分享                    |
| `/research/[slug]` | 研究笔记详情直达页  | 公开  | V2                               |
| `/admin/login`     | 后台登录       | 管理员 | Supabase Auth 登录                 |
| `/admin`           | 后台首页       | 管理员 | 内容概览、最近更新、待处理留言                  |
| `/admin/articles`  | 文章管理       | 管理员 | 列表、新建、编辑、发布、归档                   |
| `/admin/ideas`     | 想法管理       | 管理员 | V2                               |
| `/admin/projects`  | 项目管理       | 管理员 | 项目 CRUD                          |
| `/admin/gallery`   | 图片管理       | 管理员 | 图片上传、描述、分类                       |
| `/admin/research`  | 研究管理       | 管理员 | V2                               |
| `/admin/timeline`  | 时间线管理      | 管理员 | V2                               |
| `/admin/links`     | 链接管理       | 管理员 | 社交账号和外链                          |
| `/admin/widgets`   | Widget 管理  | 管理员 | Now、Latest、Status、Quote、Calendar |
| `/admin/media`     | 媒体库        | 管理员 | 图片、视频、文档、简历                      |
| `/admin/messages`  | 留言管理       | 管理员 | 查看、标记、归档                         |
| `/admin/settings`  | 站点设置       | 管理员 | 壁纸、主题默认值、SEO、个人资料                |

## 公开桌面首页

### 页面 Heading

- 主视觉 Heading：`Welcome to PanOS`
- 副标题：`小潘同学的个人操作系统`
- 英文辅助文案：`I build AI agents, web products, and strange little ideas.`

### 固定区域

| 区域 | 内容 | 数据来源 | 是否后台管理 |
| --- | --- | --- | --- |
| 顶部菜单栏 | Apple 风格标记、PanOS、当前 App 名称、Search、主题切换、时间 | 部分代码，时间来自客户端 | 部分管理，PanOS 文案不管理 |
| 桌面壁纸 | 图片或视频壁纸 | `site_settings` + `media_assets` | 是 |
| 欢迎窗口 | 标题、副标题、身份、三个按钮 | 代码配置 + `site_settings.profile` | V2 管理 |
| 桌面 Widget | Now、Latest、Status、Quote、Calendar | `widgets`、内容表派生 | 是 |
| Dock | About、Articles、Ideas、Projects、Gallery、Research、Timeline、Links、Contact | 代码配置 | 否 |
| Window Layer | 打开的 App 窗口 | 前端状态 | 否 |
| Spotlight | 搜索框和结果 | `/api/search` | 否 |

### 欢迎窗口按钮

| 按钮 | 行为 | 跳转 / 打开 |
| --- | --- | --- |
| 开始探索 | 关闭欢迎窗口，打开 About 窗口 | 桌面内状态 |
| 查看最新文章 | 打开 Articles 窗口，列表按发布时间倒序 | 桌面内状态 |
| 联系我 | 打开 Contact 窗口 | 桌面内状态 |

### 顶部菜单栏

菜单高度固定为 36px。移动端为状态栏样式，高度 44px。

#### 左侧 `PanOS` 下拉菜单

| 菜单项 | 行为 |
| --- | --- |
| About PanOS | 打开 About 窗口 |
| System Preferences | 打开 Preferences 面板，支持主题和壁纸预览 |
| Contact Me | 打开 Contact 窗口 |
| Restart Intro | 重新显示欢迎窗口 |

#### 右侧按钮

| 按钮 | 行为 |
| --- | --- |
| Search | 打开 Spotlight |
| Theme | 在浅色、深色、跟随系统之间切换，保存到 localStorage |
| Clock | 显示当前本地时间，只读 |

## Dock 应用

Dock 固定在桌面端底部居中。移动端显示底部常驻 Dock + 主屏 App 网格。

| App | Heading | 图标 | 点击行为 | 内容来源 | 后台管理 |
| --- | --- | --- | --- | --- | --- |
| About | About This Pan | 身份卡 / 用户 | 打开 About 窗口 | 静态配置 + `site_settings` | V2 |
| Articles | Articles | 文档 | 打开 Articles 列表窗口 | `articles`、`categories`、`tags` | 是 |
| Ideas | Ideas | 灯泡 | 打开 Ideas 窗口 | `ideas`、`tags` | V2 |
| Projects | Projects | 工具箱 | 打开 Projects 窗口 | `projects`、`project_links`、`media_assets` | 是 |
| Gallery | Gallery | 图片 | 打开 Gallery 窗口 | `gallery_items`、`media_assets` | 是 |
| Research | Research | 节点 / 原子 | 打开 Research 窗口 | `research_notes`、`categories`、`tags` | V2 |
| Timeline | Timeline | 时钟 | 打开 Timeline 窗口 | `timeline_events` | V2 |
| Links | Links | 链接 | 打开 Links 窗口 | `social_links` | 是 |
| Contact | Contact | 邮件 | 打开 Contact 窗口 | `site_settings`、`contact_messages` | 是 |

## App 详细模块

### About App

Heading：`About This Pan`

模块：

| 模块 | 内容 | 数据来源 | 后台管理 |
| --- | --- | --- | --- |
| 头像 / Memoji | 头像图片 | `media_assets` 或代码默认图 | 是 |
| 基础身份 | 潘廷峰 / Pan Daniel、身份标签 | `site_settings.profile` | V2 |
| 一句话介绍 | 探索 AI Agent、个人产品、Web 开发和内容创作之间的连接方式 | 代码默认 + 设置覆盖 | V2 |
| System Info | Model Name、Chip、Memory、Version、Status | `site_settings.profile` | V2 |

按钮：

| 按钮 | 行为 |
| --- | --- |
| View Projects | 打开 Projects 窗口 |
| Read Articles | 打开 Articles 窗口 |
| Contact | 打开 Contact 窗口 |

### Articles App

Heading：`Articles`

列表窗口模块：

| 模块 | 内容 | 数据来源 | 后台管理 |
| --- | --- | --- | --- |
| 左侧分类栏 | All Articles、AI & Agent、Web Development 等 | `categories(module='articles')` | 是 |
| 分类方式切换 | 「按分类」（左侧分类栏）/「按时间」（卡片按年·月分组） | 前端状态 | 否 |
| 文章卡片流 | 封面、标题、摘要、分类、日期、阅读时间，点击进入窗口内详情 | `articles` | 是 |
| 撰写入口 | 工具栏「写文章」按钮，跳转 `/admin/articles`（需登录） | 前端 | 否 |
| 空状态 | “这里还没有内容...” | 代码文案 | 否 |

文章卡片按钮：

| 按钮 / 区域 | 行为 |
| --- | --- |
| 卡片整体 | 在窗口内打开文章详情，同时更新 URL 为 `/articles/[slug]` |
| 标签 | 应用标签筛选 |
| Share | 复制文章链接 |

详情页模块：

| 模块 | 内容 | 数据来源 |
| --- | --- | --- |
| 标题区 | 标题、摘要、标签、发布时间、阅读时间 | `articles` |
| 正文 | MDX 渲染、代码高亮、图片、视频、LaTeX | `articles.body_mdx` |
| 右侧目录 | 根据正文 heading 生成 | 前端渲染 |
| 阅读进度 | 滚动进度条 | 前端状态 |
| 上一篇 / 下一篇 | 相邻已发布文章 | API 派生 |

| 模块 | 内容 | 数据来源 |

## 后台管理模块

后台使用传统管理界面，不使用桌面窗口隐喻，优先保证内容维护效率。

| 后台模块 | 功能 |
| --- | --- |
| Dashboard | 内容数量、最近发布、待处理留言、最近媒体 |
| Articles | 新建、编辑、预览、发布、归档、标签、分类、封面 |
| Ideas | V2，新建、编辑、状态流转、标签 |
| Projects | 新建、编辑、链接、截图、状态、技术栈 |
| Gallery | 上传图片、设置分类、描述、工具、下载权限 |
| Research | V2，研究方向、笔记、进度、标签 |
| Timeline | V2，按日期维护动态 |
| Links | 维护社交账号、排序、启用禁用 |
| Widgets | 维护桌面 Widget |
| Media | 上传、搜索、替换、复制 URL |
| Messages | 留言查看、标记已读、归档 |
| Settings | 壁纸、SEO、个人资料、联系信息 |

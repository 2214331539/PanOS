# 数据库设计文档

版本：v0.1  
日期：2026-06-07

## 基本规则

- 数据库使用 Supabase PostgreSQL 16。
- ORM 使用 SQLAlchemy 2.0 async。
- 数据库迁移使用 Alembic。
- 表名使用 snake_case 复数名。
- 主键默认使用 UUID。
- 时间字段使用 `timestamptz`。
- 所有内容表必须包含 `created_at`、`updated_at`。
- 公开内容必须同时满足 `status='published'` 和 `visibility='public'`。
- 删除优先使用 `archived` 或 `deleted_at`，不默认硬删除。

## 表设计

### `admin_users`

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| `id` | uuid | pk | Supabase Auth 用户 ID |
| `email` | text | unique, not null | 管理员邮箱 |
| `display_name` | text | not null | 显示名 |
| `role` | admin_role | not null | 角色 |
| `avatar_media_id` | uuid | fk nullable | 头像 |
| `is_active` | boolean | default true | 是否启用 |
| `created_at` | timestamptz | default now | 创建时间 |
| `updated_at` | timestamptz | default now | 更新时间 |

索引：`email` unique。

### `site_settings`

站点设置，适合存储壁纸、SEO、个人资料、联系信息。

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| `key` | text | pk | 设置键，如 `profile`、`wallpaper`、`seo` |

| `value` | jsonb | not null | 设置内容 |

| `updated_by` | uuid | fk nullable | 更新人 |
| `updated_at` | timestamptz | default now | 更新时间 |

约定 key：

| key | value 内容 |
| --- | --- |
| `profile` | 姓名、英文名、身份标签、当前关注、头像 |
| `wallpaper` | 当前壁纸 media id、类型、暗色/浅色覆盖层 |
| `contact` | 邮箱、微信二维码、简历 media id、联系说明 |

## 初始种子数据

V1 初始化必须包含：

- `categories(module='articles')`：AI & Agent、Web Development、Product Thinking、Entrepreneurship、Life Notes、Essays。
- `categories(module='projects')`：AI Projects、Web Apps、Product Experiments、Research Tools、Content Experiments。
- `categories(module='gallery')`：Photography、AI Images、UI Design、Posters、Screenshots、Visual Experiments。
- `social_links`：GitHub、小红书、抖音、Bilibili、Email。

- `site_settings.profile`、`site_settings.contact`、`site_settings.wallpaper`、`site_settings.seo`。

## 迁移原则

1. 修改字段前必须先更新本文档。
2. 删除字段必须先提供数据迁移方案。
3. 新增表必须补充 API 文档和后台管理说明。
4. 内容状态和枚举值不得在代码中随意拼写，必须使用统一 enum。
5. 所有 Alembic migration 文件必须可重复部署到 Preview 和 Production。
